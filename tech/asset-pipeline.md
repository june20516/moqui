# 에셋 파이프라인

## 원칙
1. **에셋 때문에 진행이 막히면 안 된다.** 모든 기능은 화이트박스로 먼저 완성하고, 에셋은 M10에서 교체한다.
2. **라이선스가 확인되지 않은 에셋은 넣지 않는다.**
3. **스타일은 셰이더로 통일한다.** 출처가 달라도 공통 툰 셰이더와 팔레트를 입힌다 (spec/10).

## 조달 우선순위
1. **직접 생성 (코드):** 툰 셰이더(URP, HLSL 또는 Shader Graph), 외곽선, 날개·물방울·소용돌이 셰이더, 절차적 메시(날개, 거미줄, 단순 가구), 효과음 합성(스크립트로 WAV 생성).
2. **허용 라이선스의 무료 에셋 다운로드** (자동 다운로드 가능한 것만):
   | 후보 | 용도 | 기대 라이선스 |
   |---|---|---|
   | Kenney (kenney.nl) | 가구, UI, 효과음 | CC0 |
   | Quaternius | 인간 캐릭터 + 애니메이션, 소품 | CC0 |
   | Poly Haven | 소품 모델, HDRI, 텍스처 | CC0 |
   | ambientCG | 텍스처 | CC0 |
   | OpenGameArt | 효과음, BGM | 항목별 확인 |
   표의 라이선스는 기대값이다. **다운로드 시점에 해당 페이지에서 직접 확인**하고 기록한다.
3. **사람 요청 (로그인/구매/수작업 필요):** Mixamo 애니메이션, Unity Asset Store, VRoid Studio 커스텀 캐릭터, VRoid Hub, Sketchfab 다운로드, 이미지 생성 AI. → `plan/progress.md` "사람 요청"에 필요한 사양(파일 형식, 본 구조, 폴리곤 수, 배치 경로)을 구체적으로 적는다.

## 라이선스 허용 목록
- 허용: CC0, CC-BY 3.0/4.0 (크레딧 필수), MIT, Apache-2.0, Unity Companion License(Unity 공식 패키지).
- 금지: 라이선스 불명, NC(비상업), ND(변경 금지), "개인 사용만", 게임 추출(리핑) 에셋, 출처가 불분명한 재배포본.

## 캐릭터 "모키" 조달 전략 (위에서부터 시도)
1. 라이선스가 허용되는 휴머노이드 베이스(예: Quaternius CC0 캐릭터)에 코드로 만든 날개, 주둥이, 리본 메시를 부착하고 툰 셰이더를 적용한다.
2. 1이 스타일상 맞지 않으면, 프리미티브 조합 데포르메 캐릭터(구 머리, 캡슐 몸, 절차적 머리카락 덩어리, 날개)를 코드로 만든다. 애니메이션은 절차적으로 처리한다(기울기, 날개 진동, 스케일 펄스).
3. 고품질 VRoid 모델은 사람 요청으로 등록한다. 교체가 쉽도록 캐릭터 뷰를 `PlayerVisual` 프리팹 하나로 분리하고, 애니메이터 파라미터 이름을 고정해 둔다.

## 인간 캐릭터
- CC0 리깅 휴머노이드 + 포함된 애니메이션을 우선 쓴다. 앉기/눕기 자세는 본 회전으로 고정 포즈를 만들고, 머리 회전과 팔 공격은 Core가 계산한 포즈를 따르는 IK/절차적 애니메이션으로 처리한다. 손으로 만든 애니메이션을 쓰면 판정 프록시를 베이크한다 (`tech/architecture.md` §4.6).
